## Prerequisites

This mod is built specifically for **Codename Engine**. Make sure you meet the following requirements before installing:

- **Codename Engine** (Latest stable build recommended)
- A system running **Windows 10/11**, **Linux**, or **macOS**
- An archive extraction tool (7-Zip, WinRAR, or default OS extractor)

---

## How to Install

### Option A: Standard Mod Folder (Recommended)
1. Download the latest release from the [Releases page](https://github.com/Logise1/FNFKirbyDreamsForgotten/releases).
2. Extract the downloaded `.zip` file.
3. Open your **Codename Engine** folder and navigate to the `mods/` directory.
4. Move the extracted `KirbyDreamsForgotten` folder directly into `mods/`.
5. Launch **Codename Engine**.
